# Bloblang Documentation Reference

This directory contains local copies of the Bloblang documentation used to implement the [Tree-sitter grammar for Bloblang](https://github.com/teyfix/tree-sitter-bloblang).

## Source

These files were sourced from the official Redpanda Connect documentation: [https://docs.redpanda.com/redpanda-connect/guides/bloblang/](https://docs.redpanda.com/redpanda-connect/guides/bloblang/)

## Files

- `arithmetic.md`: Operators, numerical, and boolean comparison logic.
- `methods.md`: Standard library methods and type coercion references.
- `advanced.md`: Complex patterns, custom CSV mapping, and flow control.
- `functions.md`: Global function definitions and usage patterns.
- `walkthrough.md`: General language overview and testing workflows.
